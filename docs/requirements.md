# 产品需求与范围

## 产品定位

UNSEEN 是面向年轻人的城市探索与个人成长平台，帮助用户把线上灵感变为上海真实世界中的活动、地点、体验和连接。它是一份持续生长的个人生活档案，不是无限滚动的社交媒体。

品牌表达：

- Life has more than one version.
- Turn inspiration into experience.
- As we wander, we become.

## 用户与平台

- 首要用户：希望发现城市体验、尝试新事物并记录成长的年轻人。
- 城市：上海，首版内容使用虚构演示数据。
- 顶部提供国家与城市选择器（可滚动列表 + 搜索），作为界面偏好；当前只有上海的演示内容，选择其他城市时不会切换内容，也不得让用户误以为其他城市已有内容。
- 选择器中的国家与城市列表目前为演示占位数据，尚未代表真实业务覆盖；覆盖城市需由项目方确认。加入项目的地区包括中国香港、中国澳门与中国台湾。
- 语言：**中文 / English 两个独立版本**，由页头国家城市选择器右侧的语言选择图标（🌐 + 当前语言）切换，选择立即生效并保存在本机（`unseen:locale:v1`）。两个版本不在同一页混排：不采用「中文段落下跟英文段落」的写法。**中文版**页面内的眉题与子标签一律中文（原来「等宽英文眉题 + 中文正文」的编辑感混排已按项目方要求作废；`FEATURED`、`WHAT'S INSIDE`、`EVENT SCHEDULE`、`DIRECTORY`、`DREAM ARCHETYPE` 等纯英文眉题删除或改写为中文，`ENTRY DATE / 入梦日期` 这类双语标签只留中文），**保留英文的只有品牌与体系标识**：主导航 `DISCOVER / HOME / IDENTITY / COLLABORATE / ABOUT`、字标 `REVERIE®` / `UNSEEN®`、`UNSEEN® / CITY PASSPORT`、页脚 `AS WE WANDER, WE BECOME.` / `UNSEEN® / SHANGHAI`，以及展位号、票号、`ISSUE 002` 这类编号与 `Cos` / `Lolita` / `BJD` 这类品类专名。**英文版不出现中文**（`REVERIE` / `UNSEEN BOX` / `REALMVIEW` 等专有名词除外）。术语、英文稿与逐页进度记入 `docs/i18n-glossary.md`，按页面与项目方逐页确认后落地。HOME 的五个子栏目标签中文版为「探索 / 内容 / 活动 / 商店 / 空间」（英文版 `EXPLORE / CONTENT / EVENTS / SHOP / SPACE`）；在线商店的四个来源分类英文版为 `Independent creators / Artist merch / Niche imports / REVERIE originals`。
- 导航：桌面端主航栏列出全部五项（`DISCOVER / HOME / IDENTITY / COLLABORATE / ABOUT`），**五项都不带序号**（原先的 `01`–`05` 已按项目方要求删除）；**后两项原先的英文副标签 `Partners / Open Calls` 与 `Story / Contact` 也已按项目方要求删除**，导航项只剩一行主标签。桌面端顶部保留头像入口（`E01`，进入 IDENTITY）。手机端（≤760px）底栏只保留三项 `DISCOVER / HOME / IDENTITY`（HOME 居中，选中项用黄色图标强调），顶部只保留字标、国家城市选择器与 `MORE ↗`（头像 `E01` 在手机端隐藏，因为 IDENTITY 已在底栏）。`COLLABORATE` 与 `ABOUT` 不占底栏，改由 `MORE ↗` 拉出全屏菜单选择，菜单内只保留两组共五项：`COLLABORATE`（品牌招募 `PARTNER WITH US` / `OPEN CALL` 报名参与）与 `ABOUT`（About REVERIE 一句话定义 / Past Projects 做过的事 / Contact 按用途找我们），分组标题只用英文组名（原先的 `Partners / Open Calls`、`Story / Contact` 小字同样已删除），选中后切到对应栏目并滚到对应区块。桌面端主航栏右侧在 `COLLABORATE` 之前有一排四个社交渠道标志（小红书 / 抖音 / 公众号 / 微信，单色简笔图形，右对齐，仅桌面端显示，且与右侧分组之间不用竖线分隔；窄桌面（≤1000px）下收起以免把导航挤到溢出）：小红书为项目方确认的账号外链（新窗口打开），其余三个的账号与二维码待项目方提供（当前待定），点击只给演示提示；标志带 `title` / `aria-label`，且不能只靠 hover 才能辨认。
- 设备：iPhone Safari 优先的移动端网页，同时适配桌面浏览器。顶部两行（品牌行 + 主导航行）在页面滚动时保持可见，向下滑也能直接切栏目；DISCOVER 的三项板块导航粘在这两行下方。
- 进入方式：无需登录或手机号，打开网页直接进入 `DISCOVER`；本产品不提供账号体系。

## 核心循环

`Discover → Choose → Experience → Connect → Record → Reflect → Next`

用户发现少量相关体验，选择并参与；可加入活动小队或线下空间，随后用文字记录和反思，形成下一步建议。首版以可点击演示方式表现，不连接真实服务。
