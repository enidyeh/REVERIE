## 阻塞与风险
- 本次只做了「色彩 + 外壳视觉语言」。参考里的其他视觉语言（`✱` 星形标记、胶囊/描边按钮、超大展示字与水印大字、颗粒感渐变图）尚未逐页落地，目前按钮与边框仍为直角，需项目方确认是否继续推进。
- 参考中的黄底按钮、白字标题等具体用法是逐页取舍的，本次统一按「深蓝底 + 酸黄文字 + 紫强调」执行；若项目方希望某些区块反转（酸黄底 + 深蓝字，例如卡片或 CTA），需要指定区块。
- `--paper` / `--pink` 仍是历史令牌名，现在的含义已与名字不符（酸黄主文字 / 紫色强调）。重命名会改动所有样式表，本次未做，已记入待办。
- `src/index.css` 里 `--blue` 现与 `--pink` 同值（参考里没有蓝色）；如后续需要第三个强调色需重新定义。（E47 后 `--blue` 与 `--accent` 同值 `#a89bff`。）
- 本轮新增的 44px 触控目标与 13px 最小字号会让部分密集区块变高（例如筛选栏、卡片按钮），首屏内容量比改版前少；需真机确认是否需要局部收紧。
- 未在真实 iPhone Safari 上复验：圆角与投影的滚动性能、黄条导航在 iOS Safari 地址栏收起/展开时的粘顶表现均需真机确认。
- 图片仍是 23 处 Unsplash 外链，无 `width` / `height`，只有 3 处 `loading="lazy"`；离线不可用，且会把访问者 IP 暴露给第三方 CDN。
- HOME 的 EXPLORE / EVENTS / SHOP / SPACE 仍只有 HOME 的 h1，其中 EVENTS 与 SPACE 存在 h1 → h3 跳级（删页头的副作用，本轮未动）。
- 新增依赖 Vitest 只用于开发与 CI，不进产物；`npm ci` 在离线环境下会失败。
