# 开发日志

本目录记录开发协作中的可核实进展，供项目阶段交接和回顾使用。

## 规则

- 文件按日期命名：`YYYY-MM-DD.md`，使用项目所在地当天日期。
- 每次开发协作开始时创建或续写当天日志；收尾时更新完成事项、实际验证、阻塞和下一步待办。
- 只记录已发生的工作和真实运行过的检查。计划中的工作放在待办，不写成已完成。
- 如果当天没有开发协作，不创建空日志。此机制由协作流程维护，不是后台定时任务。
- 不记录手机号、密码、令牌、密钥、私人对话或其他敏感数据。
- 阶段变更应与 `../development-plan.md` 对应，必要时在日志中注明阶段验收结果。

## 日志模板

```markdown
# 开发日志 YYYY-MM-DD

## 已完成
- ...

## 验证
- ...

## 阻塞与风险
- 无 / ...

## 下一步待办
- ...
```
