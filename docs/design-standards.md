# 视觉与交互设计规范

## 设计方向

UNSEEN 应像一本记录个人真实生活的移动杂志：编辑式排版、数字档案、青年亚文化和未来身份系统并置。界面重内容和行动，不做通用 SaaS 面板或社交媒体信息流。

2026-10-09 起视觉参考项目方提供的《第一版 NEURO GROWTH.pdf》：深海军蓝底、酸黄主文字与黄条导航、紫色强调、10px 圆角的卡片与图片、20px 圆角按钮、克制的自然投影；只参考视觉，内容与页面框架不变。

## 色彩

视觉参考：项目方提供的《第一版 NEURO GROWTH.pdf》（深海军蓝底 + 酸黄主色 + 紫强调）。

| 用途 | 令牌 | 色值 |
| --- | --- | --- |
| 主背景 | `--ink` | `#051120` |
| 主文字与标题（酸黄） | `--text` | `#F7F864` |
| 次要文字 | `--muted` | `#8E9BA3` |
| 细线 / 边框（黄） | `--rule` | `rgba(247, 248, 100, .26)` |
| 强调（浅紫，正文可用） | `--accent` | `#A89BFF` |
| 深强调 / 按钮填充（紫） | `--accent-fill` | `#8B7CE8` |
| 酸黄底上的深色文字 | `--on-acid` | `#051120` |
| 抬升面 / 面板底 | `--panel` | `#0A1B2E` |
| 图片遮罩 | `--shade` | `rgba(5, 17, 32, .88)` |

令牌名称为 2026-10-09 统一后的命名（原先的 `--paper` / `--pink` / `--violet` 已分别改名为 `--text` / `--accent` / `--accent-fill`，页面级令牌由 `--<页面>-paper` 改为 `--<页面>-text`）。

默认背景与主文字色写在 `:root`，页面级色调（`--theme-paper`、`--market-muted` 等）沿用同一套值。

- 大面积使用深海军蓝背景与酸黄文字；紫色只用于强调、激活态、标签与装饰点。
- 酸黄只做「深底上的亮色」或「深色文字的黄底」（例如主导航行黄条），**不得把酸黄同时用作底色和文字色**。
- 紫色已按 2026-10-09 要求调亮降低饱和度：`--accent` `#A89BFF` 在深蓝底上对比度约 **7.9:1**（AA 达标，可直接用在 13px 小字上）；按钮填充用 `--accent-fill` `#8B7CE8`，其上的文字必须是深蓝 `--ink`（**不能用白字**，白字在它上面只有 3.4:1）。
- 次级灰已统一为冷灰（`#B9C6CE` / `#9FADB4` / `#7C8B93` 三档），不再使用暖米色系。
- 确保正文和控件有足够对比度；颜色不作为唯一状态提示。

## 排版与构图

字体上限（硬性约束，2026-10-09 收紧）：

- 英文只使用一个字体族：等宽 `SFMono-Regular / Menlo / Consolas`，用于全部英文大写标签、编号、日期、坐标和数值。
- 中文只使用一个字体族：黑体 `PingFang SC`。**不再使用宋体**（`--zh-serif` / `--serif` 已删除，全部标题与正文改用 `--sans`；票据图片的 canvas 字体也已改为黑体）。
- 不引入其他字体；字体族在 `src/index.css` 的 `--en / --zh-sans` 中集中定义，其他文件只引用 `--sans / --mono`，不得再写具体字体名。

字号：只有两档——标题与正文（2026-10-09 定稿，同日再调一次尺寸）。

- 标题内部递进三级：`--title-lg` 桌面 40px / 移动 30px（页面主标题）、`--title-md` 28px / 22px（区块与栏目标题、弹层标题、品牌字标）、`--title-sm` 18px / 16px（卡片与列表标题）。
- 正文：桌面端统一 **15px**（`--text-md` / `--text-sm` / `--text-xs` 同值，覆盖段落、说明、按钮与控件文字、编号、日期、地点、标签、计数）——即「桌面正文再放大两号」；移动端 `--text-md` / `--text-sm` 仍为 **13px 保持不变**，只有最小档 `--text-xs`（编号 / 日期 / 地点 / 标签等标注）缩到 **12px**，对应「手机版最小字体缩小一号，正文字体不变」。
- 任何新增文字必须落在「标题三级」或这两个正文档位内；桌面端不得出现小于 15px 的文字，移动端不得出现小于 12px 的文字（实测：桌面各页最小字号 15px、首段 15px；390px 移动端最小 12px、首段 13px）。
- 例外的只有非文字性质的装饰尺寸（护照印章、引号装饰、票面「夢」字），它们不参与文字层级。

圆角、投影与触控（2026-10-09 新增，集中在 `src/surfaces.css`）：

- 图片与卡片统一 **10px** 圆角；圆形元素（头像、社交标志、圆形箭头按钮、进度点）保持 50%。
- 卡片带自然投影：`0 12px 26px rgba(2, 9, 18, .45), 0 2px 6px rgba(2, 9, 18, .3)`，不叠加多层重投影。
- 所有按钮统一 **20px** 圆角（文字链接按钮同样适用）。
- 所有触控目标至少 **44×44**：按钮、下拉、输入框、文字链接都有 `min-height: 44px`，其中品牌字标、`MORE` 按钮、头像、社交标志、列表右侧圆形按钮均已实测为 44px 以上。

字号与行高的引用方式：

- 所有字号通过 `src/index.css` 的六个令牌与 `@media (max-width: 760px)` 断点统一控制，页面样式表不得再单独覆盖字号。
- 使用 `font` 简写时配对行高令牌，例如 `font: var(--text-xs)/var(--text-xs-leading) var(--mono)`。
- 例外的只有非文字性质的装饰尺寸：IDENTITY 护照印章（`clamp(78px, 32cqw, 124px)`，跟随卡片宽度缩放）、购票弹层票面的「夢」印章（`56px`）与引号装饰（`86px`），它们不参与文字层级。

其他：

- 使用有编辑感、易读的字体组合；优先选择项目可稳定加载的字体，不依赖未经确认的外部字体服务。
- 标题有明确层级，正文适合手机阅读；避免用视口宽度直接缩放字号。
- 使用强网格、细边框、档案编号、日期、地点、类别等元数据，构造有秩序的内容节奏。
- 卡片只用于单个体验、商品或活动等重复条目；不要用层层嵌套卡片包裹整页区域。
- SHOP 的商品区是「一张商品精选大卡 + 卡片网格」：大卡展示当前筛选与排序结果里的第一件（左图右文，图上标 `FEATURED / 商品精选`），其余商品用同一种小卡片排网格（宽屏 4 列、`≤1100px` 3 列、`≤760px` 2 列）；同一件商品不得同时出现在大卡与网格里。
- 纯说明性质的多标签行（如 EVENTS 页首的 `OPTIONAL FORMATS / 可选形式` 九项）用等宽小字的方框标签、`flex-wrap` 自然换行呈现，不写成按钮、不加 hover 态，避免看起来可点；只有标签真的会筛选或跳转时，才升级成按钮并补上选中态与无障碍状态。标签行本身不横向滚动（否则会带动页面横向溢出）。
- 栏目允许没有页头：EXPLORE、EVENTS、SHOP 与 SPACE 都已删除 `.section-meta`（如 `HOME / SPACE · YOUTH SPACES · SHANGHAI`）与栏目自己的定位说明 / 大标题，直接从栏目内容开始（EVENTS 从形式标签行开始，SHOP 从 `小小的东西，有很大的来处。` 标题开始，SPACE 从偏好筛选开始），此时第一个区块要自己承担页面顶部间距，不能出现「内容直接顶到粘顶栏目条」的情况。
- 城市活动、商品和空间应使用能展示真实对象的编辑摄影或可靠图片素材，不使用纯装饰性图形代替主体内容。
- 仅装饰性的大号字（护照印章、引号等）不属于标题层级，可保留独立尺寸。
- IDENTITY 的 CITY PASSPORT 是**横向卡片**：固定 `aspect-ratio: 8 / 5`（实测 320–1440px 下比值均为 `1.60`），宽度跟随所在栏；卡内装饰印章用容器查询单位（`cqw`）跟随卡片宽度缩放，不写死像素，避免窄屏卡高变矮后印章溢出。卡内元素一律不得超出卡边界。
- DISCOVER 首屏：开屏与三项板块导航必须同时落在首屏内，不需要下滑；开屏高度用 `clamp()` 结合 `100svh` 控制；实测 320×568 也能满足（窄屏可收紧开屏内各处间距来腾空间，不靠隐藏系列名）。
- 顶部两行（品牌行 `.app-header` + 主导航行 `.main-nav`）在滚动时始终粘顶可见，高度写在 `:root` 的 `--app-header-h` / `--app-nav-h`（`--app-top-h` 为两者之和；≤760px 时主导航行隐藏，第二项为 `0px`）。两行都要不透明背景（`var(--ink)`）并向内补出外壳的左右内边距（`margin` 负值 + 同等 `padding`），否则内容会从两侧滑过；**不加 `backdrop-filter`**，它会成为固定定位后代的包含块，会弄坏挂在头部里的弹层（如城市选择器）。层级：品牌行 `z-index: 9`、主导航行 `8`，必须低于站内弹层（20–40）。
- 任何粘顶导航都会遮住锚点顶部：跨栏目跳转的目标（`.collab-*` / `.about-*`）与页尾「回到页首」（`.page-content`）都要设 `scroll-margin-top`。DISCOVER 的标签条与 HOME 的五个栏目条都粘在 `top: var(--app-top-h)`；DISCOVER 的滚动落点由 `MonthlyThemeView` 用 JS 计算（已包含顶部两行的高度），HOME 的栏目条只需切栏目即可。
- 两处粘顶标签条都要向外补出外壳内边距（`margin: 0 -56px; padding: 0 56px`；≤760px `-20px / 20px`；≤370px `-16px / 16px`）与不透明背景，使第一个标签与页面内容左边界对齐；窄屏保持条内横向滑动而不是换行。
- 弹层（如购票流程）：宽屏居中、窄屏贴底并限制高度（`92svh`）内部滚动；必须有明确的关闭按钮，支持 Esc 与点背板关闭，关闭后焦点交还给触发元素；打开时锁定页面滚动。
- 表单输入在窄屏最小高度不低于 `46px`，主按钮沿用 `.theme-primary-action`（窄屏满宽）。
- 栏目标签条（HOME 的五个同级栏目）：窄屏允许标签条自身横向滚动（隐藏滚动条、标签不换行不收缩），但页面本身不得产生横向滚动。
- 品牌字标 `.wordmark` 使用 `--title-md`，不单独定义字号。

## 移动端

- 从窄屏开始设计；底部导航、表单、详情操作适配单手触控和 iPhone 安全区。
- 底部导航（≤760px）固定三项（`DISCOVER / HOME / IDENTITY`，HOME 居中），只放主入口；`COLLABORATE` 与 `ABOUT` 这类次级入口收进顶部右侧的 `MORE ↗` 菜单，避免底栏拥挤。菜单为全屏面板（底部对齐、内部滚动、复用站内弹层规则），每项最小高度 48px。
- 手机端顶部只保留字标、国家城市选择器与 `MORE ↗`（头像按钮在 ≤760px 隐藏，桌面端保留）；顶部控件不得因文字变化造成换行或溢出。
- 主航栏右侧的社交标志右对齐（靠 `margin-left: auto`，与 `COLLABORATE` 之间留 `32px`，与导航项的节奏一致），标志本身不加左右竖线，右侧分组也不再画分隔线：用对齐与间距分层，不用框线。顶部两行都不得出现横向溢出，窄桌面下优先收起社交标志而不是缩小导航项。
- 固定格式控件应预设稳定尺寸，状态和文案变化不应造成布局跳动。
- 交互目标至少约 44 × 44 CSS 像素；操作不能只依赖 hover。
- 长标题、商品名和地点名必须能换行，不裁切、不覆盖邻近内容。
- 关键内容在桌面布局也保持清晰的内容宽度和网格关系，不简单拉伸手机单列。

## 动效与状态

- 动效少而有目的，用于内容进入、选择确认或导航反馈；不牺牲加载性能和可读性。
- 遵循 `prefers-reduced-motion`，减少非必要位移和自动播放。
- 所有可操作状态提供明确的 hover（适用时）、focus-visible、pressed、selected 和 disabled 表现。
- 成功、失败、空状态需有清楚的文字反馈；颜色不能作为唯一状态提示。

## 无障碍

- 使用语义化标题、按钮、导航和表单标签；图像提供有意义的替代文本。
- 键盘可以访问全部功能，焦点顺序符合视觉顺序且焦点清晰可见。
- 正文、边界和交互状态符合可读对比；不把小号低对比元数据作为唯一关键信息。
